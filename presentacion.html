06 / CHALLENGES & SOLUTIONS

Retos Técnicos Superados y Aprendizajes

Reto 1: Maquetación Responsive

Adaptación Multidispositivo

Solución: Implementación de CSS Grid con auto-fit, funciones minmax() y aspect-ratio junto con object-fit: cover para garantizar proporción perfecta en cualquier resolución.

Reto 2: Navegación Móvil

Menú Hamburguesa Accesible

Solución: Desarrollo de menú interactivo en JavaScript vanilla ligero con transiciones CSS suaves, gestión de clases de estado y atributos aria-label.

Reto 3: Modularidad CSS

Prevención de Colisiones de Estilos

Solución: Separación estricta entre estilos globales (global-styles.css) y estilos dedicados por vista (catalog-styles.css, etc.) con selectores específicos.

Reto 4: Sincronización en Git

Coordinación en Equipo

Solución: Comunicación constante en equipo, ramas feature independientes por tarea y pull requests revisados antes de mergear a dev.
